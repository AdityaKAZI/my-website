# Aditya Thapa — Portfolio

## Deploy with GitHub Pages

1. Create a GitHub repository.
2. Upload the contents of this folder to the repository root.
3. Keep `index.html` and the `assets` folder side by side.
4. Open **Settings → Pages** in the repository.
5. Under **Build and deployment**, choose **Deploy from a branch**, select your main branch and `/ (root)`, then save.

GitHub Pages will publish the site after deployment finishes.
